# SMS Spam Detection Using Machine Learning

## Project Overview
SMS Spam Detection is a beginner-friendly machine learning project that classifies text messages into two categories: **SPAM** and **NORMAL**. It helps identify unwanted or promotional messages.

## Objectives
- Identify spam and normal SMS messages.
- Learn the basics of machine learning.
- Train a model using a labeled dataset.
- Test the model on new messages.

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib
- Kaggle Dataset

## Machine Learning Workflow
1. Load the dataset.
2. Clean and prepare the data.
3. Separate messages and labels.
4. Convert text into numerical features using TF-IDF.
5. Train a Random Forest classification model.
6. Evaluate the model using accuracy, a classification report, and a confusion matrix.
7. Test new messages and display predictions.

## Example

**Spam Message:**
"URGENT! You have won a FREE prize. Call now to claim!"

**Normal Message:**
"Hello, how are you? See you tomorrow."

The model predicts whether a message is SPAM or NORMAL. Predictions depend on the trained model and may not always be correct.

## Dataset
The project uses the SMS Spam Collection dataset from Kaggle.

Download the dataset from [Kaggle](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset).

## How to Run
1. Open the project notebook in Google Colab.
2. Upload the dataset file named `spam.csv`.
3. Run the notebook cells in order.
4. Check the model's evaluation results.
5. Test your own SMS messages.
